# CreationsXAI — Website

AI Automation Agency landing page.

## Deploy on Netlify

1. Drag and drop this folder into [app.netlify.com](https://app.netlify.com/drop)
2. Done — your site is live instantly.

## Deploy via GitHub

1. Push this folder to a GitHub repo
2. Import the repo in Netlify
3. Leave build settings blank and click Deploy
